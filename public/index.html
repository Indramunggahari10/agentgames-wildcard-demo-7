Preflight Doctor

Sign, verify, and debug the Agent Games handshake — HMAC-SHA256, lowercase hex, no prefix, over the exact raw body bytes, in the x-agent-games-signature header. The preflight response must be exactly {ok: true, protocolVersion: 'v1'}.

Honest scope. This is an educational demo. It never calls the real platform, never stores anything, and never logs what you paste. But it is a hosted server: whatever you paste is sent to this demo server and processed in memory. Use a disposable test secret — never your real one. Inputs are UTF-8 text; a text box cannot represent arbitrary raw bytes.
